
# Shield-Updater
**Codex was used to write the C++ code**

Shield Updater est un homebrew gratuit pour 3DS/2DS qui vérifie et installe les mises à jour des applications Shield directement depuis la console. L’interface est pensée pour la Old 3DS.

## SHIELD Theme Music

 L’application recherche les `BGM.ogg` des thèmes Anemone dans `sdmc:/themes/`, y compris dans les ZIP, permet de les écouter, puis copie le fichier sous le nom du thème en `.ogg`. Elle demande confirmation avant de remplacer un fichier existant. Les dossiers contenant des MP3 sont proposés en priorité. Le format OGG a été testé sur 3DS par le créateur.



Le code de Theme Music Extractor et son archive source sont sous licence MIT. Les licences des bibliothèques tierces sont fournies séparément dans l’archive.

I’m on the hardware side, so using Codex is actually an advantage—though it doesn’t mean I’m not doing any work myself.
