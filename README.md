# Shield-Updater

Shield Universal Updater est un homebrew gratuit pour Nintendo 3DS/2DS qui vérifie et installe les mises à jour des applications Shield directement depuis la console. Une interface simple, pensée pour la Old 3DS, permet de suivre les versions disponibles et installées.

## Shield Radio

Shield Radio est ajouté à la liste intégrée à partir de Shield-Updater 1.1.4 (CIA interne 8).
