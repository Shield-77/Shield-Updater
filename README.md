# Shield-Updater


Shield Universal Updater est un homebrew gratuit pour 3DS/2DS qui vérifie et installe les mises à jour des applications Shield directement depuis la console. L’interface est pensée pour la Old 3DS.

## SHIELD Theme Music


Ajouté à Shield Updater 1.1.8 (CIA interne 13). L’application recherche les `BGM.ogg` des thèmes Anemone dans `sdmc:/themes/`, y compris dans les ZIP, permet de les écouter, puis copie le fichier sous le nom du thème en `.ogg`. Elle demande confirmation avant de remplacer un fichier existant. Les dossiers contenant des MP3 sont proposés en priorité. Le format OGG a été testé sur 3DS par le créateur.


[**Télécharger ShieldThemeMusicExtractor.cia v1.0.0**](https://github.com/Shield-77/Shield-Theme-Music-Extractor/releases/download/v1.0.0/ShieldThemeMusicExtractor.cia) — SHA-256 : `319075cf26d67ad9ca0ab98a9b558b73e9634a784a8aca05e2b2b2d10bda72b4`.


[Release Shield Updater 1.1.8](https://github.com/Shield-77/Shield-Updater/releases/tag/v1.1.8) — asset : `ShieldUniversalUpdater.cia`, SHA-256 : `f1ebddd3fbbd94a73b5d4a2fcfde58f083f08526b8f89474d1e4ac9d4d422983`.
